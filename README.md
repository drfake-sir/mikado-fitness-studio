# Mikado Fitness Studio

Single-page website for **Mikado Fitness Studio**, a coach-led strength studio in Valasaravakkam, Chennai.

Live site: https://drfake-sir.github.io/mikado-fitness-studio/

## About

- Imperial Japanese-inspired design: rising-sun rays, seigaiha waves, kintsugi seams, sakura petals and a hanko seal.
- Command palette (`Ctrl` / `⌘` + `K`), booking flow, timetable, body calculator, membership planner, gallery lightbox and live open/closed status.
- Light and dark themes, reduced-motion support, keyboard navigation and accessible dialogs.
